# Run on OpenClaw's native Telegram channel instead of our own bot

Until October 2026 this repository also held a Bun/grammY service in front of OpenClaw that authenticated users, provisioned an agent per user, routed the owner's messages between gods (pin, then keywords, then an LLM classifier), transcribed voice notes and delivered reminders through loopback `/notify` and `/tell` endpoints. OpenClaw 2026.9.7 ships all of it natively, so `src/`, the Docker files and `pantheon.service` were deleted rather than maintained alongside the channel they duplicated; the repo now holds only what OpenClaw does not ship (`README.md:12-19`). The rejected alternative was keeping the bot in front as a router: it would have retained a second process polling a second copy of every message, for behaviour the platform already owned. Migration detail is in `docs/superpowers/specs/2026-09-30-native-telegram-migration-design.md`.
