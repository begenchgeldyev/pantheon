# Personas are templates, not runtime configuration, and CI does not deploy them

`gods/<id>/` and `workspace-template/` are rendered by hand into live workspaces and then edited in place on the server, because agents mutate their own workspaces and `gods/` is kept in step manually; directory enumeration is explicitly not an agent selector, since parked templates sit beside live ones (`README.md:26-28`). The rejected alternative was treating `gods/` as the deployable source of truth and copying it over live workspaces on every deploy: that would overwrite memory the agents wrote themselves and resurrect templates for gods that are not configured. One consequence: parked gods stay as persona templates plus retained history instead of being deleted, so the repo's file listing is not a roster — consult `openclaw agents list --bindings` (`docs/superpowers/specs/2026-11-12-pantheon-reliability-design.md:183`).
